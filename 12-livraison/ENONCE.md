# Livraison reproductible

## Contexte
Une application web doit rester fiable lorsque les conditions changent.

## Travail demandé
Permettre à un pair de démarrer et tester l’application sur une installation propre.

## Contraintes et critères d’acceptation
Documenter les prérequis, les commandes, l’architecture et les routes. Build de production sans erreur. Aucun secret commité. Le pair rapporte les difficultés.

## Livrables
Commit final, README, journal de vérification signé par le pair.

## Temps indicatif
Deux périodes, avec finalisation dans le projet individuel.
