# États réseau et composants

## Contexte
Une application web doit rester fiable lorsque les conditions changent.

## Travail demandé
Construire un écran listant des données provenant de l’API Node.js et isoler son rendu dans un composant Vue.

## Contraintes et critères d’acceptation
Le chargement, l’absence de résultat et les erreurs HTTP produisent trois états explicites. Une interaction permet de relancer une requête. Le DOM n’est pas manipulé hors du cycle de vie Vue.

## Livrables
Application lancée, code source, commit et fiche de tests.

## Temps indicatif
Deux périodes, avec finalisation dans le projet individuel.
