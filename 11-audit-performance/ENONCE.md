# Audit de performance

## Contexte
Une application web doit rester fiable lorsque les conditions changent.

## Travail demandé
Comparer deux variantes d’animation qui produisent un résultat visuel comparable.

## Contraintes et critères d’acceptation
Une variante provoque une modification géométrique (left), l’autre utilise transform. Capturer deux traces DevTools avec protocole identique. Tester le clavier et reduced motion.

## Livrables
Traces annotées, décision technique motivée, correctif intégré au projet.

## Temps indicatif
Deux périodes, avec finalisation dans le projet individuel.
